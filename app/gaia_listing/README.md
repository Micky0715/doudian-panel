# 盖亚发品模块边界

本目录负责“型号输入 → 价格规则表查 ID → 双维成色模板生成 → 上传执行状态”。不负责抖店商品编辑、图片上传或抖店发布。浏览器动作独立放在 `integrations/gaia_browser/`。

## 2026-09-24 当前链路（后文旧阶段记录不代表当前按钮行为）

1. 选择店铺、成色，填写手机型号，一行一个；可写 `苹果,iPhone 17 Pro` 或完整品牌型号。
2. 只点一次“开始执行”：读取空模板与直播货架价格规则表，只用明确国行记录。读取 `拍拍标品skuId`，不是货品 ID 或价格。更换映射表等分步操作在默认收起的“高级设置”中。
3. 一个明确品牌/型号的颜色、容量 ID 全部展开；重复 ID 只写一次。跨品牌、不同型号或缺失型号仍阻断。不把整个价格规则目录作为发布清单。
4. 填写 A:H，逐行回读并校验源文件/输出哈希。单文件最多 2000 个 ID。
5. 上述校验通过后自动调用 `POST /batches/<id>/start`，绑定店铺和文件哈希；后台打开专用浏览器，选店、数量 1、上传副本，回读后点击确定。不再要求第二次点击，可能需要在专用窗口登录。
6. 前端轮询进度。重复启动复用原批次，盖亚浏览器同时只执行一批，不改动抖店四并发调度。点击前持久化提交意图；回执缺失、点击超时或进程中断进入待核对，不自动重试。

`gaia_accepted` 仅表示页面明确成功反馈，**不代表逐行创建完成或抖店发布成功**。本轮无真实最终提交，页面反馈识别仍待真实验收。`config/gaia_execution.json` 控制启动入口，`GAIA_LISTING_V1_ENABLED=0` 可紧急关闭。“开始执行”包含真实盖亚提交；高级设置的“仅生成文件”不会触发提交。

下载目录无权限时，发现接口仍会列出受控副本。导入接口仅按合法版本 ID 复用，重新校验源文件及索引哈希、路径与国行策略；不放宽任意路径访问，不产生重复副本。界面标明使用已保存版本，不能称其为下载目录的最新文件。用户手选文件优先；无效文件停止，不静默换用旧版本。

新增边界：`application/model_resolution.py` 展开指定型号；`application/upload_execution.py` 管理执行、文件锁和状态；`integrations/gaia_browser/upload_form.py` 准备并回读表单；`submit.py` 负责一次最终点击和反馈；`upload_preflight.py` 始终只取消、不提交；`assets/gaia-workspace.js` 编排一键流程与表单；`assets/gaia-execution.js` 管理上传启动、进度轮询、防重入与恢复。抖店前端不承担盖亚编排。

### 停止任务（2026-09-24）

“开始执行”旁的“停止”不在禁用的参数 fieldset 内。准备阶段停止后，等待当前读取或生成请求结束，不再执行下一步；如刚生成批次，则取消同一批次。浏览器阶段调用 `POST /api/gaia/batches/<id>/stop`，校验店铺及输出文件哈希，并在同一批次锁内与提交意图互斥。停止成功后状态为 `cancelled`，活动浏览器先显示 `stopping`，安全退出后为 `stopped`；保留 Excel 和审计记录。

本地停止不能撤回盖亚任务。提交意图已记录时，停止返回 409，继续回读原批次结果，不重试确定、不改成已取消。等待登录、下拉搜索、文件回读和最终提交前均检查停止状态；正在等待的单次浏览器操作会在返回/超时后的安全点退出，不强杀其他任务。前端丢弃停止前发出的旧轮询响应，防止已停止状态被覆盖。

停止交互修正（`gaia-stop-2`）：准备/上传阶段显示“停止任务”，点击即显示“正在停止…”；服务确认取消且浏览器退出后显示“已停止”。已进入提交阶段显示“已提交，无法撤回”，按钮下方直接说明原因，不再只禁用按钮。准备阶段取消失败、停止响应丢失时不会误报“已停止”；显示“停止待确认”并查询原批次，阻止重复启动。启动、停止和状态查询的 HTTP 传输有 10 秒超时，超时不等于服务端任务取消；不会自动补发启动/停止请求。停止回读确认取消后，即使原停止响应丢失，也按服务端取消状态显示。关闭页面清理计时器和未完成的状态请求，不代表后台任务自动停止。

提交反馈保留 `observed_feedback` 和 `gaia_submit_feedback` 日志，识别“没有对应 goodsId”等拒绝提示。拒绝仍然不会自动重提；只见普通提示、未取得成功回执时仍为 `manual_required`。

离线验收：`python3 -m scripts.gaia_model_workflow_canary` 在临时目录用真实映射与模板生成并回读，不打开浏览器、不提交。回归：`python3 -m unittest discover -s tests -p 'test_gaia*.py'` 和 `node --test tests/test_gaia_execution_ui.cjs`。

## 旧阶段记录

阶段 B2 已接入模板预览、生成和下载。型号映射只接受 `.xlsx`/`.csv`；上传成功后保存独立版本、SHA-256 与有效标品 SKU 数。下载目录里的“抖音直播货架货品价格规则数据导出（货品维度）”是映射来源，不是上传模板。导入时若存在“标品名称”列，只保留明确包含“国行”的数据；非国行或未标注行数及 SKU 数会记入版本审计信息。源文件不会被修改。生成时必须另外提供本次明确选择的 standardSkuId 清单，不能把整个参考目录误当成铺货任务。系统重新校验模板、映射版本和成色 ID，只复制空模板到独立输出目录，写入 A:H 后逐行回读并记录输出哈希。前端“开始”会串联最新空模板识别、映射导入、预览、生成和上传前校验；盖亚网页最终提交和抖店交接仍保持独立阶段。

接口：`POST /api/gaia/model-mappings/import-download` 只接收下载目录中唯一识别的货品维度导出；`POST /api/gaia/model-mappings/resolve` 复用本地图库的品牌/型号归一化规则，只返回候选，不会在同型号的多个 SKU 中猜选。`POST /api/gaia/batches/preview` 返回前 20 行及总行数；`POST /api/gaia/batches/generate` 要求携带预览返回的 `source_sha256` 和 `quality_id` 作为 `expected_source_sha256`、`expected_quality_id`；`GET /api/gaia/batches/<id>/download` 在文件哈希一致时才提供下载。`GET /api/gaia/qualities/status` 可查看成色 ID 是否配置。盖亚导入专用成色编码由运营于 2026-09-24 确认：99新 → `99`，95新 → `95`，写入模板 E 列；不得使用抖店属性 3320 的选项 ID `18972`/`18954`。成色配置每次读取，修改后即时用于新预览/生成；旧预览及旧批次被成色一致性校验拦截，须重新生成，不覆盖历史 Excel 或提交记录。

阶段 C 的准备检查已实现为只读 `GET /api/gaia/batches/<id>/handoff-preflight?shop_id=<店铺ID>`：重新核对批次状态、店铺、数量 1、源模板与型号映射哈希、当前成色 ID、输出文件哈希；只在全部一致时返回交接清单和稳定幂等键。它不确认批次、不打开盖亚、不上传文件。浏览器上传仍须在已登录页面可连接、真实成色 ID 和型号映射已核实后单独验收。

2026-09-13 已增加独立 Playwright 页面探测 `integrations/gaia_browser/probe.py`。在真实已登录盖亚页面验证了“抖音渠道 → 双维成色发品 → 批量操作弹窗”、店铺下拉、数量 1、文件选择器和取消按钮；未选择店铺或文件，也未点击“确定”。它尚未接入面板任务或任何真实上传流程，详见 `integrations/gaia_browser/README.md`。

非表格部分已补上本地批次生命周期控制：`POST /api/gaia/batches/<id>/cancel` 要求目标店铺和 2～300 字取消原因，在原子读改写下仅允许盖亚提交前的状态取消；重复取消只返回原结果、不重复记事件。已提交批次返回冲突，绝不能被本地标为取消。取消保留生成文件供审计，不删除、不上传。`GET /api/gaia/batches/<id>` 可查看状态和事件。这里的“取消”只是阻断未来由本程序发起的提交，不是盖亚网页中的撤销。

抖店草稿关联目前只有保守匹配器，尚未接入自动交接：必须有同店、全量分页、校验和正确的提交前后草稿快照、新增商品的详情回读（品牌、型号、成色），以及盖亚回执中逐行对应的商品 ID。标题相似、草稿数量相同，甚至同期唯一同型号草稿，都不能单独作为成功证据；缺少回执关联或同一草稿对应多行时进入待核对。真实详情回读和盖亚受理回执关联仍待下一阶段实现。

## 当前已落地

| 文件 | 单一职责 | 禁止承担的职责 |
| --- | --- | --- |
| `domain/template_contract.py` | 定义真实盖亚模板 A:H 列及固定填写规则 | 读写 Excel、浏览器、HTTP |

| `infrastructure/model_mapping_repository.py` | 保存通过校验的运营映射文件、版本及哈希 | 生成盖亚模板或提交网页 |

| `application/draft_matching.py` | 利用完整快照和已核实详情保守关联草稿 | 按标题猜测、按数量视为成功 |
| `infrastructure/batch_repository.py` | 本地批次原子保存和修改锁 | 盖亚页面状态判定 |
| `infrastructure/template_writer.py` | 保留原模板结构，只写输出副本 A:H | 覆盖原模板、决定业务字段 |
| `api/routes.py` | 把前端请求交给应用层并返回结果 | 重复业务规则 |

## 当前填写合同

| 列 | 规则 |
| --- | --- |
| A 场域 | 前端选择 `1` 直播间或 `2` 直播货架 |
| B 聚合标识 | 固定 `A` |
| C 是否质检链接 | 固定 `1` |
| D 标品 ID | 本次任务明确提供的 standardSkuId，且必须存在于已版本化映射目录 |
| E 抖音成色 ID | 前端选择成色后，查询运营确认的精确 ID |
| F 名称前缀 | 留空 |
| G 选品策略 | 仅“手机”填 `D且E且G`，其他品类留空 |
| H 商品规则前缀 | 默认小写 `a`（不要混同 B 列聚合标识 `A` 或 F 列名称前缀） |

成色 ID 未维护、型号未唯一命中、模板表头不匹配，均为阻断错误；系统不得猜测或写入替代值。
